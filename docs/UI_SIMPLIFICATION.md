# 默认精简模式

本阶段不删除账号、项目版本、结构化结果、知识库或企业服务流程等后端能力，而是通过渐进披露降低默认界面的复杂度。

## 默认顶部入口

新增能力在顶部只保留：

```text
项目
知识库
账户 / 登录
```

“服务流程”不再占用顶部空间。在组织空间中打开一个已保存项目后，可以从“项目”窗口点击“服务跟进”进入。

## 默认保留的核心路径

```text
新建或打开项目
填写企业资料
选择会议 / 合同 / 政策等任务
AI 生成
人工复核
保存项目版本
导出结果
```

人工复核、项目保存、官方政策来源和结果事实边界仍直接可用。

## 默认折叠的信息

精简模式默认折叠：

- 原始结构化 JSON、复制和下载 JSON；
- SHA-256、载荷哈希和上下文哈希；
- 知识库完整版本与审核记录；
- 人工复核完整审计时间线；
- 服务流程完整操作记录。

这些数据仍然存在，没有从数据库或接口中删除。结构化结果、知识库和人工复核弹窗提供局部“显示高级信息”入口；完整技术与审计界面可从项目窗口切换到高级模式。

## 服务流程

服务流程后端继续保留六个节点。精简界面按三组展示：

```text
第 1 步：收集需求
第 2 步：处理与跟进
第 3 步：完成与归档
```

每组仍包含原有节点和审核门槛，不改变流程状态机和审计记录。

## 高级模式

项目窗口提供“显示高级功能 / 返回精简模式”切换，选择保存在浏览器：

```text
zhilian_ui_mode_v1
```

高级模式恢复顶部服务流程入口、完整 JSON、哈希、版本细节和审计记录。

## 移动端

在 760px 以下：

- 项目、知识库和账户入口均分可用宽度；
- 服务流程保持在项目窗口内；
- 项目操作按钮使用两列布局；
- 高级信息开关单独占一行。
